# Instrucciones para Claude Code

## Autoría de commits

Los commits de este repositorio deben llevar únicamente la autoría del usuario.
No incluyas en los mensajes de commit:

- La línea `Co-Authored-By: Claude ...`
- La firma `🤖 Generated with [Claude Code](https://claude.com/claude-code)`
- Cualquier otra referencia a Claude o Claude Code como autor o colaborador

Esto aplica a todos los commits y pull requests creados en este repositorio a partir de ahora.
